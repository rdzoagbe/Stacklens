# Innov'up Île-de-France — Stacklens application dossier

This folder is the working dossier for the Innov'up grant (Région Île-de-France /
Bpifrance), prepared from the *StackLens Innov'up Grant Preparation Guide 2026*.
It is written to be read by the founder and reused as the source of every claim
in the application. Nothing in it was left as a placeholder that could be
answered from the code; what is left blank needs a fact only the founder has
(bank documents, interview notes, time actually spent).

**Position in one sentence:** the funded project is not "build Stacklens". It is
*"Development and experimental validation of an intelligent SaaS environment
discovery, utilisation and access-risk analysis engine for small and mid-sized
organisations"* — a defined R&D programme with measured starting points and
measurable end points. The starting points are in `02-technical-baseline.md`
and were produced by the shipped code, not written by hand.

## What the code now provides for the dossier

- **A measured technical baseline.** `src/lib/baseline.js` scores the shipped
  engine (`src/lib/saasAudit.js`) against three labelled sets in
  `test-data/innovup-baseline/`. `src/lib/baseline.test.js` fails if the
  numbers in the dossier stop matching the code.
- **Activation evidence.** `src/lib/activation.js` records first data arrival,
  first insight (once, with minutes since sign-up and since data), returns on
  later days, and which inbox recommendations were shown and acted on. Counts
  and minutes only; the analytics privacy guard checks every call site.
- **The security and privacy facts**, each with the file that makes it true.

## Two rules this dossier follows

1. **No number without a source.** Technical numbers come from the scripts and
   tests in this repository. Commercial numbers are marked *[founder]* until a
   document or interview note backs them.
2. **The engine is not improved before filing.** The misses in the baseline are
   the evidence that the project exists. Fixing them now would be starting the
   funded work early, and Innov'up does not fund what has already been done.
   Ordinary maintenance of the product continues; the *inference* engine is
   frozen at the recorded commit until the application is submitted.
